# Pixnais Studio (desktop)

Пиксельный редактор Pixnais Studio как программа для Windows (Electron).

## Как собрать exe
Сборка происходит сама на GitHub: при каждом пуше в main (или кнопкой Run workflow
во вкладке Actions) собирается портативный PixnaisStudio-1.0.0.exe.

## Где скачать
Страница Releases -> релиз "Pixnais Studio (Windows)" -> файл PixnaisStudio-1.0.0.exe.
Файл портативный: просто запусти, установка не нужна.

Шрифты Press Start 2P, VT323 и Pixelify Sans загружаются при сборке из google/fonts (лицензия OFL).
